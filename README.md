# Unemployed to Unstoppable

- We came across this idea when we were brainstorming about the huge setbacks famous people came across. 

- This is a game in which Hensen John, a CEO of one  of the biggest company just had to resign because of unforseen circumstances. 

- You the player have to help him get back his fortune and save him from enemies. Control the character with WAD.
    - A - Move left
    - D - Move Right 
    - W - Jump
-  Dodge the enemies and get AI chip to get the bounty.

- You have Grek, an AI robot  to assist you in the beginning of the game and it makes you familiar with the storyline. Help Hensen Juang and GET THE GLORY

  Technical Details:
   - Game Engine - Godot - 4.7.1
